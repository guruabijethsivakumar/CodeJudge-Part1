# CodeJudge Part 1 - Relational Design, Keys and Normalization

This repository contains Part 1 solution for the CodeJudge DBMS assignment.

Files included:

- schema_explanation.md -> understanding of raw dataset tables
- keys_and_relationships.md -> primary keys, foreign keys, constraints
- normalization_notes.md -> normalization analysis
- schema.sql -> relational database schema using SQL DDL
- erd.md -> relationship diagram in text format
- assumptions.md -> design assumptions
- data/ -> raw dataset files

Tools used:
- GitHub
- Git Bash
- VS Code
- SQL concepts from DBMS

This design converts raw CSV data into a structured relational database schema.
